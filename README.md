CellShopCenter – Repositorio

Este repositorio contiene dos partes del proyecto CellShopCenter, organizadas por ramas:

Rama main

Contiene el proyecto API RESTful, encargado de toda la lógica del sistema:
productos, inventarios, proveedores, compras, ventas y autenticación.

Rama appmovil

Incluye la aplicación móvil de CellShopCenter, la cual consume la API y ofrece la interfaz para gestión e interacción del usuario.

Organización

main → Backend (API RESTful)

appmovil → App móvil
